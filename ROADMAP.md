# Roadmap: October 2026–October 2027

These are intended priorities, not completed features or guaranteed deadlines.
Security and compatibility fixes take precedence over new functionality.

1. Preserve the shared JVM/ES5 contracts and cross-runtime regression tests while
   keeping source releases, consumer delivery and physical-device acceptance separate.
2. Follow up the native PBKDF2 migration with supported-browser acceptance and
   recovery evidence; measure performance only on the actual named targets.
3. Qualify complete network and dependency profiles, including exact TLS key
   boundaries, release clients and optional build environments. Keep unverified
   badge criteria unmet until retained evidence supports them.
4. Improve measured coverage, coding diagnostics and reproducible distribution
   evidence across the core, FOSS2 and maintenance tooling.

No backup maintainer or tested one-week access-recovery process currently exists.
Record an actual arrangement when it exists; automation alone does not replace it.
